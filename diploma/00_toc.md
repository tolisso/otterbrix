## Рекомендации по сборке

Для получения единого файла в формате Word можно воспользоваться утилитой pandoc:

```bash
pandoc 01_intro_and_architecture.md 02_research.md 03_solution_design.md \
       04_implementation.md 05_optimizations.md 06_conclusion_and_benchmarks.md \
       07_references.md \
       -o diploma.docx \
       --reference-doc=template.docx
```

где `template.docx` содержит требуемое оформление (TNR 14, полуторный интервал, отступы по ГОСТ 7.32-2017).

Альтернативно файлы Markdown могут быть импортированы по отдельности в Word/LibreOffice и объединены вручную с проставлением разрывов страниц между главами.
